# Instrucciones para agregar las capturas de pantalla

## 📱 Proyecto TaskFlow (Flutter):

1. **Nombra tus capturas** exactamente así:
   - `taskflow-1.jpg` (o .png)
   - `taskflow-2.jpg`
   - `taskflow-3.jpg`
   - `taskflow-4.jpg`
   - `taskflow-5.jpg`

2. **Orden sugerido**:
   - Captura 1: Login/Autenticación
   - Captura 2: Tablero Kanban con drag & drop
   - Captura 3: Dashboard con estadísticas
   - Captura 4: Gestión de tareas/prioridades
   - Captura 5: Sistema de notas o perfil

## 📁 Ubicación:

Coloca todos los archivos en esta carpeta: `public/images/`

## 💡 Formato recomendado:

- **Formato**: JPG o PNG
- **Tamaño**: Ancho máximo 800px (se optimizará automáticamente)
- **Peso**: Menos de 500KB por imagen

## 🔧 Optimización (si son muy pesadas):

- https://tinypng.com/
- https://squoosh.app/

## ✅ Configuración:

Las rutas ya están configuradas en `src/data/projects.ts` y aparecerán automáticamente en tu portafolio con el carrusel funcional.
